## 🌟 Fonctionnalités clés

- 🔒 **Encapsulation Shadow DOM** : Pas de conflit CSS avec tes styles existants.
- 🎨 **Système de Thème Dynamique** : Support natif du Mode Sombre / Clair via variables CSS.
- ⚡ **Zéro Dépendance** : Écrit à 100% en JavaScript pur Vanilla (JS natif).
- 🧩 **+30 Composants Web Prêts à l'Emploi** : Cartes, modales, grilles, charts, barres de progression, formulaires, etc.
- 🛠️ **API Globale** : Gestion des notifications Toast, fenêtres modales et copie presse-papier intégrée.
